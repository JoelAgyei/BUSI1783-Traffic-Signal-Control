# AI Assisted Traffic Signal Control for Congestion Mitigation in UK Urban Networks

## Module
BUSI1783

## Programme
MSc Business Analytics
University of Greenwich

## Project Overview
This study investigates whether reinforcement learning can improve traffic signal control and reduce congestion in UK urban road networks using SUMO traffic simulation.
